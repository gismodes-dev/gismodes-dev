## 👋 About Me

I build **data pipelines, software, and AI-powered automation** — turning raw data and repetitive work into reliable, automated systems. Coming from a **scientific / analytical** background, I care about correctness, reproducibility, and clean engineering as much as shipping.

- 🔭 **Focus:** data engineering, backend software, and automating workflows with AI.
- 🧪 **Roots:** scientific computing with **Python**, **R**, and **LaTeX**.
- ⚙️ **Mindset:** if it's repetitive, it should be automated — and measurable.
- 💬 **Ask me about:** Python data tooling, building APIs, and AI automation.
